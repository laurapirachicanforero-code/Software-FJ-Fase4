## Descripción del proyecto

Software FJ es una aplicación de escritorio desarrollada
en Python para la gestión de clientes, servicios y reservas,
aplicando los principios de la programación orientada a
objetos y el manejo de excepciones.

## Características

- Interfaz gráfica personalizada en tonos rosados.
- Modo claro y oscuro.
- Interfaz en español e inglés.
- Registro y validación de clientes.
- Administración de servicios.
- Gestión de reservas.
- Cálculo de costos, impuestos y descuentos.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores.
- Almacenamiento temporal mediante listas.

## Tecnologías utilizadas

- Python 3.15.2
- CustomTkinter
- Visual Studio Code
- Git
- GitHub

## Estructura del proyecto

| Archivo | Función |
|---|---|
| main.py | Inicio de la aplicación |

## Instalación y ejecución

Instalar la dependencia:

    python -m pip install customtkinter

Ejecutar la aplicación:

    python main.py

Ejecutar las pruebas:

    python pruebas.py
